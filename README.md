# Adedotun Temidayo — Student Portfolio

A responsive multi-page student portfolio website for a Cybersecurity student aspiring to become a Security Engineer.

## Pages
- `index.html` — homepage and profile introduction
- `about.html` — education, career aspiration, learning areas, interests, and multimedia element
- `projects.html` — three sample project concepts with illustrations
- `planner.html` — interactive academic task planner (add, complete, delete, filter, clear completed); tasks persist in browser local storage
- `contact.html` — contact details and JavaScript form validation

## Run locally
Open `index.html` in a modern browser. No build tools are required.

## Publish online
1. Create a GitHub repository, for example `adedotun-student-portfolio`.
2. Upload the contents of this folder (keep the `assets` folder).
3. In GitHub, open **Settings → Pages**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Submit the published GitHub Pages URL and repository URL.

## Before submission
- Replace sample project concepts with your actual completed work and screenshots.
- Add any specific school/programme details you want displayed.
- The contact form currently validates in the browser only; it does not transmit messages. Connect a form backend/service if you need to receive submissions.
- The multimedia demonstration uses an externally hosted sample video and therefore requires an internet connection.
- Update the portfolio with your own photograph if desired.
